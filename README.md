# Custom Image Size

Extend an image's canvas with empty space — without resizing it, without AI.
Set a final size; if it is smaller than the original, you get an error.

Astro for the static SEO page, React for the app.

## Setup

This project uses [pnpm](https://pnpm.io/) as its package manager.

```sh
pnpm install
```

## Commands

```sh
pnpm dev       # start the dev server
pnpm build     # build the static site to dist/
pnpm preview   # preview the production build
```
